# Fenix Music 🎵

Полноценный музыкальный стриминговый сервис в стиле Яндекс.Музыки с поддержкой подписок, ленты рекомендаций, плеера и админ-панели.

## 🚀 Архитектура и стек
- **Frontend**: React.js + Tailwind CSS (современный тёмный интерфейс)
- **Backend**: Node.js + Express REST API
- **Database**: PostgreSQL (полная схема: пользователи, треки, альбомы, плейлисты, история)
- **Deployment**: Render (`render.yaml`) + GitHub-ready структура

## ⚙️ Быстрый старт
1. Клонируйте репозиторий.
2. Для бэкенда: `cd backend && npm install && npm start`
3. Для фронтенда: `cd frontend && npm install && npm start`
